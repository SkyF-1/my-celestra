# Celestra（Godot 4.6.3）

打开 `project.godot` 即可在 Godot 编辑器内运行。独立 Windows x64 包位于同级目录的 `Release/`，运行 `Celestra.exe` 即可；`Celestra.pck` 必须放在可执行文件旁。

## 操作

| 按键 | 功能 |
| --- | --- |
| A / D | 左右移动；贴墙时反向 + Space 蹬墙跳 |
| W / S | 抓墙时上下攀爬；地面 S 蹲伏；空中 S 快速下落 |
| Space | 跳跃，长按跳得更高 |
| J | 抓墙，持续消耗体力 |
| K + WASD | 八方向冲刺；不按方向时向面朝方向冲刺 |
| E | 篝火、商店、道具和终点交互 |
| B | 背包，装备或丢弃道具 |
| 1 / 2 / 3 | 使用对应栏位道具 |
| Esc | 暂停或返回游戏 |

## 实现说明

- 地块以 `Vector2i(列, 行)` 为键，随玩家移动按需生成。山脚固定，横向坐标无预设边界，顶层旗帜在接近山顶时按玩家所在列确定。普通地块有三种平台组合；另含危险地块、篝火、天赋商店、道具商店、奖励地块和终点。
- 重点实现的局内系统为天赋：四种天赋分别拥有独立价格、等级上限和即时角色效果。绿泡泡三选一；未来生成的商店会排除已满级天赋。
- 草莓先跟随玩家；离开来源地块并落地后结算。死亡时跟随的草莓回原处，已结算的草莓、天赋和道具保留。篝火改变复活位置与摄像机下移边界。
- 道具商店和奖励地块提供基础风道具，支持三个栏位、拾取替换、丢弃与使用。使用后十秒内重力和攀墙体力消耗降低。
- 数值在 `scripts/player.gd`；地图生成、经济系统与菜单在 `scripts/main.gd`。

## 验证

在工程目录运行：

```powershell
& 'E:\Godot\Standard\Godot_v4.6.3-stable_win64.exe' --headless --path . --script res://scripts/smoke.gd
```

脚本检查开局、按需生成终点、天赋购买、死亡复活与菜单操作。命令中的 Godot 路径需按本机安装位置调整。
